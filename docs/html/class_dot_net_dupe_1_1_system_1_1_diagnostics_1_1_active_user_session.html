Detailed Description

Provides system inspection facilities for active and expired user logon sessions.

Interrogates Windows Terminal Services (WTS API via WTSEnumerateSessionsW and WTSQuerySessionInformationW) to enumerate logged-in console and remote desktop users.

Note
Requires appropriate administrative privileges on Windows to query details for other users.
