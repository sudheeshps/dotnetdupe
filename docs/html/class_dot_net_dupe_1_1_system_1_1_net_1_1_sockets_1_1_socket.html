Detailed Description

Implements the Berkeley sockets interface.

Provides robust cross-platform network communication compliant with RFC 793 (Transmission Control Protocol), RFC 768 (User Datagram Protocol), and POSIX.1-2001 socket APIs. Manages socket descriptors via RAII and encapsulates Winsock / BSD socket semantics cleanly.
