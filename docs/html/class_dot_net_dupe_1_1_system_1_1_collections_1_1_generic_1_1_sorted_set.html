Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Generic::SortedSet< T >

Represents a collection of objects that is maintained in sorted order.

Template Parameters
TThe type of elements in the set.
Note
Conforms to ECMA-335 Partition IV Section 5.44 (System.Collections.Generic.SortedSet<T>). Maintains sorted unique elements using binary search insertion.
