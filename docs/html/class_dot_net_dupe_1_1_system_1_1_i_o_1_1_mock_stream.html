Detailed Description

Controllable stream implementation for unit testing IO consumers.

MockStream provides configurable capabilities (CanRead, CanWrite, CanSeek) and simulated failure modes (SetThrowOnRead, SetThrowOnWrite) to facilitate deterministic testing of stream readers, writers, and pipelines.
