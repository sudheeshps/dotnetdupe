Detailed Description

Central thread-safe static registry and entry point for application logging.

Modeled after Microsoft.Extensions.Logging factory patterns and NLog/Log4Net LogManager. Provides global logger cache, configuration management, and provider registration. [Microsoft.Extensions.Logging]
