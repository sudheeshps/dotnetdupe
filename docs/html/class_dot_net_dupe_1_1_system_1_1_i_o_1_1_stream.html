Detailed Description

Provides a generic view of a sequence of bytes.

Abstract base class for all data streams, compliant with ECMA-335 Partition IV Section 5.50 specifications. Streams encapsulate reading, writing, seeking, and lifecycle management for arbitrary underlying media.
