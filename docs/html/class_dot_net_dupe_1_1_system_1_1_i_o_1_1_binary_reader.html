Detailed Description

Reads primitive data types as binary values in a specific encoding.

Complies with ECMA-335 Partition IV Section 5.54 and IEEE 754 specifications. Supports configurable endianness (little-endian by default) and wraps underlying Stream objects with optional ownership semantics via SmartPointer.
