Detailed Description

Provides the underlying stream of data for network access.

Bridges the IO::Stream abstraction with a connected Socket, compliant with RFC 793 and ECMA-335 Partition IV Section 5.50. Does not support seeking, but provides synchronous read, write, flush, and ownership management for underlying network sockets.
