Detailed Description

Factory class used to configure logging providers and create ILogger instances.

Modeled after Microsoft.Extensions.Logging.LoggerFactory. Supports registering multiple ILoggerProvider backends (e.g. Console, File) and creates composite AggregateLogger instances dispatching to all registered providers. [Microsoft.Extensions.Logging]
