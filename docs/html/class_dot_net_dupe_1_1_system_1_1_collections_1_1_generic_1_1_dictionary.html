Detailed Description

template<typename TKey, typename TValue>
class DotNetDupe::System::Collections::Generic::Dictionary< TKey, TValue >

Represents a collection of keys and values.

Template Parameters
TKeyThe type of the keys in the dictionary.
TValueThe type of the values in the dictionary.
Note
Conforms to ECMA-335 Partition IV Section 5.38 (System.Collections.Generic.Dictionary<TKey, TValue>). Implements a closed-addressing hash table with prime modulus bucket indexing and collision resolution through singly-linked entry chains.
