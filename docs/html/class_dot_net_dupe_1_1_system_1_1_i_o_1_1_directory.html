Detailed Description

Exposes static methods for creating, moving, and enumerating through directories and subdirectories.

Note
Conforms to ECMA-335 Partition IV Section 5.48 (System.IO.Directory). Cross-platform directory manipulation adhering to Windows Win32 and POSIX filesystem conventions.
