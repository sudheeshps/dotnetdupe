Detailed Description

template<typename TKey, typename TValue>
class DotNetDupe::System::Collections::Generic::SortedDictionary< TKey, TValue >

Represents a collection of key/value pairs that are sorted on the key.

Template Parameters
TKeyThe type of the keys in the dictionary.
TValueThe type of the values in the dictionary.
Note
Conforms to ECMA-335 Partition IV Section 5.43 (System.Collections.Generic.SortedDictionary<TKey, TValue>). Maintains key-sorted element ordering using binary search.
