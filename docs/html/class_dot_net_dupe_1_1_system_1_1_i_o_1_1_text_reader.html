Detailed Description

Represents a reader that can read a sequential series of characters.

Abstract base class for character readers, compliant with ECMA-335 Partition IV Section 5.56 specifications. Provides high-level text consumption routines including Read, Peek, ReadLine, and ReadToEnd.
