Detailed Description

Central registry and dispatcher for named database backends.

Manages registration and routing of database operations to active backends (e.g. in-memory or SQLite) based on connection string database names.

Note
Thread Safety: Thread-safe. Internal registry lookup is guarded by synchronization mutex.
