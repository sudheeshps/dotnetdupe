Detailed Description

Provides a stream that uses the Transport Layer Security (TLS/SSL) protocol backed by OpenSSL.

Supports client authentication, server certificate configuration, and encrypted network I/O. Standards Conformance: RFC 8446 (TLS 1.3), RFC 5246 (TLS 1.2), RFC 6066 (Server Name Indication - SNI).
