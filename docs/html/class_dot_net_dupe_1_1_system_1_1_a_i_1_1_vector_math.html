Detailed Description

Provides static vector arithmetic and similarity metrics for floating-point embeddings.

Accumulates inner products and squared norms in IEEE 754 double precision to prevent catastrophic cancellation across high-dimensional embedding vectors (e.g., 128-D or 512-D). Thread-safe: all public methods are stateless and reentrant.

Note
Conforms to IEEE 754 Standard for Floating-Point Arithmetic and ECMA-335 Partition IV.
