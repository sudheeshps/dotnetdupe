Detailed Description

Represents EXIF and header metadata extracted from an image file or byte buffer.

Supports JPEG APP1 EXIF (TIFF IFD0 and ExifSubIFD tags), PNG IHDR dimensions, and BMP BITMAPINFOHEADER dimensions without external third-party libraries.

Note
Conforms to JEITA CP-3451 (Exif 2.3) and ISO/IEC 15948 (PNG).
