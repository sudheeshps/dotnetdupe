Detailed Description

Creates and controls execution of operating system threads.

Encapsulates native execution threads (Win32 Thread / POSIX pthread), supporting parameterless and parameterized thread starts, thread joining with timeouts, thread-local current thread tracking, and native thread ID extraction. Not thread-safe for concurrent configuration; query methods are thread-safe.

Note
Conforms to ECMA-335 Partition IV Section 5.5 (System.Threading.Thread).
See also
ThreadPool, Task
