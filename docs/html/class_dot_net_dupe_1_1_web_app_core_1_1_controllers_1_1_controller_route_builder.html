Detailed Description

template<typename TController>
class DotNetDupe::WebAppCore::Controllers::ControllerRouteBuilder< TController >

Fluent builder for binding strongly-typed controller actions to HTTP verbs and route templates.

Handles parameter extraction (route parameters, query strings, and JSON body payloads) and serializes action returns into HTTP response streams.

Template Parameters
TControllerType of the controller class deriving from ControllerBase.
Note
Conforms to RFC 9110 (HTTP Semantics) and ASP.NET Core MVC routing specifications.
See also
ControllerBase, WebApplication, WebApplicationBuilder
