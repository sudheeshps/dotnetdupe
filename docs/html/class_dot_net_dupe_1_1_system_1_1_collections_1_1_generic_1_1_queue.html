Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Generic::Queue< T >

Represents a first-in, first-out collection of objects.

Template Parameters
TSpecifies the type of elements in the queue.
Note
Conforms to ECMA-335 Partition IV Section 5.40 (System.Collections.Generic.Queue<T>). Implements FIFO collection semantics with Enqueue, Dequeue, Peek, and non-throwing Try* variants.
