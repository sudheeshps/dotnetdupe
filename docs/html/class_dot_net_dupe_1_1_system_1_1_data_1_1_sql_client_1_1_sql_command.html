Detailed Description

Represents a Transact-SQL statement or stored procedure to execute against a SQL database.

Complies with ADO.NET DbCommand specifications and ISO/IEC 9075 SQL standard. Manages parameter binding, statement execution (ExecuteNonQuery, ExecuteReader, ExecuteScalar), and result set dispatch.
