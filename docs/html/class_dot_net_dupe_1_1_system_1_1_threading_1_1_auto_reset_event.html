Detailed Description

Notifies a waiting thread that an event has occurred.

Complies with ECMA-335 Partition IV Section 5.64 specifications. When signaled, allows one waiting thread to release and automatically resets to nonsignaled state. Supports local and named cross-process event synchronization.
