Detailed Description

Provides interaction with Windows event logs and Linux syslog services.

Modeled after .NET System.Diagnostics.EventLog. Supports reading, writing, creating, and clearing system event logs across platforms. On Windows, reads via OpenEventLogW and writes via ReportEventW; on Linux, interfaces with POSIX syslog (RFC 5424).

Note
Thread Safety: Static methods and internal registry access are thread-safe.
