Detailed Description

Implementation of ILogger that outputs formatted logs to standard output.

Modeled after Microsoft.Extensions.Logging.Console.ConsoleLogger. Supports ANSI/console color rendering per log level and synchronizes concurrent writes. [Microsoft.Extensions.Logging]
