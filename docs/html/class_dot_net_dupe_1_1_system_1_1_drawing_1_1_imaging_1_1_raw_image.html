Detailed Description

Encapsulates a 32-bit ARGB raster image buffer (4 bytes per pixel: B, G, R, A in little-endian u32).

Supports native BMP loading/saving, region cropping, bilinear scaling for thumbnails, and normalized floating-point RGB tensor extraction for local ML inference.
