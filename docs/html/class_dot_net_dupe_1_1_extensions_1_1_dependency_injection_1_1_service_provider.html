Detailed Description

Default IoC service provider for resolving dependencies.

Modeled after Microsoft.Extensions.DependencyInjection.ServiceProvider. Manages singleton caching, scoped resolution lifecycles, and recursive dependency tree resolution. Implements IDisposable to dispose resolved disposable singletons on shutdown. [Microsoft.Extensions.DependencyInjection]
