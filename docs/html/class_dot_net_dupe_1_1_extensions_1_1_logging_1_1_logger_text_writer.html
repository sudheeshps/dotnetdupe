Detailed Description

Adapter that routes System::IO::TextWriter stream writes into an ILogger destination.

Enables seamless redirection of Console::Out, Console::Error, or other TextWriter streams into structured LogManager categories with configurable severity levels. [Microsoft.Extensions.Logging]
