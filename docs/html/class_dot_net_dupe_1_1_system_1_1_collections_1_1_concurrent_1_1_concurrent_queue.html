template<typename T>
class DotNetDupe::System::Collections::Concurrent::ConcurrentQueue< T >

Represents a thread-safe first-in, first-out (FIFO) collection.

Template Parameters
TThe type of the elements contained in the queue.

Provides thread-safe concurrent enqueuing, dequeuing, and peeking with RAII critical section synchronization.
