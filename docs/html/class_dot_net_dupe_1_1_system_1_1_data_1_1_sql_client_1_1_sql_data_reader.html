Detailed Description

Provides a way of reading a forward-only stream of rows from a SQL database.

Complies with ADO.NET DbDataReader specifications. Provides sequential, forward-only iteration over rows returned by an executed SQL query command, with column index / ordinal lookup and type conversion routines.
