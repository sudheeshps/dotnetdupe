Detailed Description

Provides local machine-learning face detection, 128-D embedding extraction, and identity matching.

Ships with a built-in deterministic spatial-chromatic / ITU-R BT.601 luminance-gradient backend that operates 100% offline with zero external runtime dependencies, while supporting pluggable custom backends via IFaceRecognitionBackend.

Note
Conforms to ECMA-335, IEEE 754, and ITU-R BT.601 color-space luminance standards.
See also
DetectedFace, IFaceRecognitionBackend, VectorMath
