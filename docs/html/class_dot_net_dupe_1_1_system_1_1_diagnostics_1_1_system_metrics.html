Detailed Description

Provides cross-platform diagnostic counters for CPU, memory, disk, network, processes, and services.

Interfaces directly with native platform APIs: on Windows, uses PDH (Performance Data Helper), PSAPI, IPHLPAPI, Winternl NT queries, and Service Control Manager; on Linux, inspects /proc filesystems (/proc/stat, /proc/meminfo, /proc/net/dev, /proc/[pid]/io).
