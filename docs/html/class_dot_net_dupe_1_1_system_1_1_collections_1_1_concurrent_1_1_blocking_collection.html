Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Concurrent::BlockingCollection< T >

Provides blocking and bounding capabilities for thread-safe collections implementing the Producer-Consumer pattern.

Template Parameters
TThe type of elements in the collection.
Note
Conforms to ECMA-335 Partition IV and .NET Concurrent Collections architecture. Coordinates concurrent producer and consumer threads using ConditionVariable signaling and optional bounded capacity limits.
