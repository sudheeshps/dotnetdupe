Detailed Description

High-performance reader and real-time subscriber for Windows Event Log / ETW channels.

Interfaces with the Windows Event Log API (winevt.h / wevtapi.lib) to query, paginate, count, and asynchronously subscribe to structured event channels.

Note
Thread Safety: Channel querying methods are thread-safe and guarded by internal mutexes.
