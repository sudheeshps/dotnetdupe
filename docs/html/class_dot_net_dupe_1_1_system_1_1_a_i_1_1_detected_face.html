Detailed Description

Represents a detected face region and its 128-dimensional L2-normalized feature embedding.

Encapsulates pixel-space bounding box coordinates, detection confidence in [0.0, 1.0], and a unit-norm 128-D float embedding vector suitable for cosine similarity clustering.

Note
Conforms to ECMA-335 Partition I Section 8.9 (System.Object) and IEEE 754.

FaceRecognitionEngine, IFaceRecognitionBackend, VectorMath
