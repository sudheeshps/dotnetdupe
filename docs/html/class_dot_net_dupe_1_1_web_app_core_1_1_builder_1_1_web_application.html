Detailed Description

Configures HTTP request pipelines, minimalist routing endpoints, WebSockets, and hosts web servers.

Models ASP.NET Core minimal API hosting in C++ with integrated Dependency Injection, multithreaded worker pools, and controller mapping. Thread-safe for route registration prior to Run(); immutable during execution.

Note
Conforms to RFC 9110 (HTTP Semantics) and ASP.NET Core Minimal API specifications.
See also
WebApplicationBuilder, HttpContext
