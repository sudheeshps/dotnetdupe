Detailed Description

Facilitates initialization and configuration of dependency injection services, controllers, and web application hosting.

Mirrors the ASP.NET Core WebApplicationBuilder hosting model, providing a unified container for registering IoC service dependencies and dispatching MVC/REST controller routes.

Note
Thread Safety: Instance methods are not thread-safe and must be invoked during application bootstrap before calling Build().
Conforms to ASP.NET Core minimal hosting specifications and RFC 9110 HTTP architecture.
See also
WebApplication, ServiceCollection, ControllerRouteBuilder
