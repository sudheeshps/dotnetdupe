Detailed Description

Computes a Hash-based Message Authentication Code (HMAC) using the SHA-256 hash function per RFC 2104.

Mirrors .NET System.Security.Cryptography.HMACSHA256, providing symmetric key hashing for message integrity verification and token signing.
