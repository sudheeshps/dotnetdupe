Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Concurrent::ConcurrentBag< T >

Represents a thread-safe, unordered collection of objects.

Template Parameters
TThe type of the elements to be stored in the collection.
Note
Conforms to ECMA-335 Partition IV and .NET Concurrent Collections architecture. Bags are useful for storing objects when ordering doesn't matter and operations are thread-safe.
