Detailed Description

Writes primitive types in binary to a stream and supports writing strings in a specific encoding.

Complies with ECMA-335 Partition IV Section 5.55 and IEEE 754 specifications. Supports configurable endianness (little-endian by default) and wraps underlying Stream objects with optional ownership semantics via SmartPointer.
