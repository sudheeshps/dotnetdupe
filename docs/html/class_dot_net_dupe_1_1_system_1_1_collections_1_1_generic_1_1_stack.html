Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Generic::Stack< T >

Represents a variable size last-in-first-out (LIFO) collection of instances of the same specified type.

Template Parameters
TSpecifies the type of elements in the stack.
Note
Conforms to ECMA-335 Partition IV Section 5.41 (System.Collections.Generic.Stack<T>). Implements LIFO collection semantics with Push, Pop, Peek, and non-throwing Try* variants.
