Detailed Description

Sends HTTP requests and receives HTTP responses from a resource identified by a URI.

Supports standard HTTP verbs (GET, POST, PUT, DELETE), header manipulation, Pimpl ABI isolation, and seamless stream and byte array conversions. Conforms to RFC 9110 (HTTP Semantics) and RFC 9112 (HTTP/1.1).
