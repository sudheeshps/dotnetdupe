Detailed Description

Provides a synchronization primitive that can be used to block a thread, or multiple threads, until another thread modifies a shared variable and notifies the ConditionVariable.

Complies with POSIX pthread_cond_t and ISO C++11 condition variable specifications. Integrates with CriticalSection via custom lock adapters, providing Pulse (notify_one) and PulseAll (notify_all) semantics.
