Detailed Description

Provides a pool of threads that can be used to execute tasks, post work items, and process timers.

Manages worker threads across an internal work queue, automatically scheduling tasks as worker threads become idle. Thread-safe for all concurrent operations.

Note
Conforms to ECMA-335 Partition IV Section 5.15 (System.Threading.ThreadPool).
