Detailed Description

Encapsulates all HTTP-specific information about an individual HTTP request and response pair.

Serves as the central execution context passed throughout the WebAppCore pipeline, controller actions, and middleware handlers.

Note
Thread Safety: Not thread-safe; lifetime is scoped to a single request-response cycle on a worker thread.
Models ASP.NET Core HttpContext per RFC 9110 specifications.
