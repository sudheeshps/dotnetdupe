Detailed Description

Provides functionality to serialize objects to JSON strings and deserialize JSON strings to objects.

Complies with RFC 8259 and ECMA-404 specifications. Converts C++ objects and primitives into JSON text and deserializes JSON text into strongly typed C++ objects via JsonConverter specializations.
