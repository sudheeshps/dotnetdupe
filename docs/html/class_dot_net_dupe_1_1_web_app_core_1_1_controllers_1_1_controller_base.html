Detailed Description

Base class for MVC/REST API controllers mirroring ASP.NET Core ControllerBase.

Provides core facilities for extracting HTTP request headers and parameters, serializing JSON responses, evaluating RFC 7519 JSON Web Token (JWT) bearer authentication, and formatting standard HTTP status responses.

Note
Thread Safety: Controller instances are transiently instantiated or initialized per request and are not shared across threads.
Conforms to RFC 9110 (HTTP Semantics) and RFC 7519 (JSON Web Tokens).
See also
HttpContext, ControllerRouteBuilder, JWTToken
