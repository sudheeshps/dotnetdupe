Detailed Description

Represents an X.509 v3 certificate containing public and private keys conforming to RFC 5280.

Encapsulates native OpenSSL X509 and EVP_PKEY pointers to provide certificate parsing, validation, and cryptographic handshake support for TLS and HTTPS services.
