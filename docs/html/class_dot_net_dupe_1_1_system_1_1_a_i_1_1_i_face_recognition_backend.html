Detailed Description

Pluggable backend interface for face detection and 128-D feature embedding extraction.

Enables applications and unit tests to inject custom neural inference backends (e.g., ONNX Runtime, TensorRT, or deterministic test mocks) into FaceRecognitionEngine.

Note
Conforms to ECMA-335 interface contract semantics.
