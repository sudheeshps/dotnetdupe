Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Concurrent::ConcurrentEnumerator< T >

Enumerates a snapshot of elements from a concurrent collection.

Template Parameters
TThe element type.

Captures an immutable snapshot of the collection taken under mutual exclusion, allowing lock-free and thread-safe iteration without holding locks.
