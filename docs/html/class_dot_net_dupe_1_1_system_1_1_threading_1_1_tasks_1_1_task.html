Detailed Description

Represents an asynchronous operation.

Provides task scheduling on the ThreadPool, completion synchronization via ManualResetEvent, and status querying (Created, Running, RanToCompletion, Faulted, Canceled). Thread-safe for concurrent status queries and Wait() invocations.

Note
Conforms to the .NET Task-based Asynchronous Pattern (TAP).
See also
ThreadPool, Thread
