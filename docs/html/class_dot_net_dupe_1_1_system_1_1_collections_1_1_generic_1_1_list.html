Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Generic::List< T >

Represents a strongly typed list of objects accessible by index.

Template Parameters
TThe type of elements in the list.

Implements dynamic array resizing with amortized O(1) additions, binary search, sorting, and placement new allocation without STL container leakage.
