Detailed Description

template<typename T>
class DotNetDupe::System::Collections::Generic::List< T >

Represents a strongly typed list of objects accessible by index.

Template Parameters
TThe type of elements in the list.

Implements dynamic array resizing with amortized O(1) additions, binary search, sorting, placement new allocation, and full .NET IList<T> interface compliance.

Note
Thread Safety: Public static members of this type are thread safe. Instance members are not guaranteed to be thread safe. Standard Citation: ECMA-335 CLI Common Language Infrastructure.
