Detailed Description

Represents errors that occur during WebSocket connection operations and message framing.

Inherits from DotNetDupe::System::SystemException and encapsulates structured WebSocketError codes alongside platform-specific error numbers.

Note
Conforms to RFC 6455 (The WebSocket Protocol).
See also
WebSocket, WebSocketError, SystemException
