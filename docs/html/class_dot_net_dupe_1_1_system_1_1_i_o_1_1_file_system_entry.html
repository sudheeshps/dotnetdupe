Detailed Description

Encapsulates path, 64-bit size, timestamps, and attributes for a filesystem entry.

Populated directly from OS directory enumeration structures (WIN32_FIND_DATAW on Windows, stat/dirent on POSIX) to eliminate redundant per-file open/stat system calls during parallel disk scanning.

Note
Conforms to ECMA-335 Partition IV Section 5 (System.IO).
See also
Directory, FileInfo, FileAttributes
