Detailed Description

Provides a set of methods and properties that you can use to accurately measure elapsed time.

Complies with ECMA-335 Partition IV Section 5.67 specifications. Utilizes high-resolution hardware timers (QueryPerformanceCounter on Win32, CLOCK_MONOTONIC / std::chrono::steady_clock on Linux) to provide sub-microsecond timing precision without drift.
