Detailed Description

Represents the standard input, output, and error streams for console applications.

Provides thread-safe methods to read and write characters, lines, formatted strings, control console attributes (colors, cursor positions, title), and redirect standard streams. All static output methods synchronize internally using recursive mutexes.

Note
Conforms to ECMA-335 Partition IV Section 5.12 (System.Console).
