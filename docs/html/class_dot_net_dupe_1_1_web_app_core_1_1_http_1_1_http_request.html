Detailed Description

Encapsulates an incoming HTTP request within the WebAppCore pipeline.

Provides access to the HTTP method, URI path, headers, query parameters, route values, and body content.

Note
Thread Safety: Not thread-safe; processed by a single worker thread per connection.
Conforms to RFC 9110 (HTTP Semantics) and RFC 9112 (HTTP/1.1).
See also
HttpResponse, HttpContext
