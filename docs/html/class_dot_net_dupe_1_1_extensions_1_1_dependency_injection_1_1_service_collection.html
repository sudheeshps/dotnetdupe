Detailed Description

Default implementation of the IServiceCollection interface.

Modeled after Microsoft.Extensions.DependencyInjection.ServiceCollection. Serves as the primary registration builder for application services, which compiles into an immutable ServiceProvider via BuildServiceProvider(). [Microsoft.Extensions.DependencyInjection]
