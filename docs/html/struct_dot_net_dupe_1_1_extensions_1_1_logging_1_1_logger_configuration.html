Detailed Description

Encapsulates logging system configuration options.

Modeled after Microsoft.Extensions.Logging configuration patterns. Supports loading settings from JSON files or raw JSON strings, setting minimum levels, choosing plain text or JSON output formatting, and setting file paths. [Microsoft.Extensions.Logging]
