Detailed Description

Provides properties and instance methods for inspecting and manipulating a single file.

Caches file metadata upon Refresh() to minimize repeated filesystem stat calls.

Note
Conforms to ECMA-335 Partition IV Section 5.50 (System.IO.FileInfo).
See also
File, FileSystemEntry, Directory
