Detailed Description

Controls the lifetime of a scoped service.

Modeled after Microsoft.Extensions.DependencyInjection.IServiceScope. Scopes encapsulate child containers where services registered with ServiceLifetime::Scoped are resolved as singletons within that scope and disposed when the scope is disposed. [Microsoft.Extensions.DependencyInjection]
