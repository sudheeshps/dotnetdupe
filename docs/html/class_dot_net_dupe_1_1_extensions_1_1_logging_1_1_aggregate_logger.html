Detailed Description

Composite ILogger implementation that fans out log messages to multiple underlying loggers.

Dispatches Log invocations across all added child loggers, continuing dispatch even if individual sinks encounter errors. IsEnabled returns true if any child logger is enabled. [Microsoft.Extensions.Logging]
