Detailed Description

Represents an abstract SQL statement or stored procedure to execute against a data source.

Modeled after .NET System.Data.Common.DbCommand and adhering to the ADO.NET specification. DbCommand serves as the base abstraction for database commands across in-memory, SQLite, and relational database providers.

Note
Thread Safety: DbCommand instances are generally not guaranteed to be thread-safe. Concurrent execution of commands on the same instance must be synchronized externally.
